How it works

Haggle Garage is a portfolio project about building and attacking LLM agents. The dealer, Sam, is an AI agent (Google ADK + Gemini). Every game gets its own secret minimum price.

  • Level 1, Naive: the minimum is written in Sam's instructions.
  • Level 2, Hardened: same secret, plus defensive rules and an output filter in code.
  • Level 3, Blind: Sam never sees the minimum; a pricing engine in code decides every counteroffer.

At every level, code refuses any sale below the minimum. The model talks, code decides.

Source code and evaluation results: see the GitHub repository linked from the author's profile.

Privacy

We store what you type in a game (to show the transcript and evaluate the agent) for up to 30 days. Your IP address is never stored: only a salted hash that changes every day, used for rate limiting. There are no accounts and no cookies. Please do not type personal data.

All cars are real models described with public facts, but every listing, history and price is fictional. Not affiliated with any manufacturer.
